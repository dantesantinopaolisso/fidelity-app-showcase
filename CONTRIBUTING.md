# Comentarios y sugerencias

Este repositorio presenta el producto; no contiene el código de la aplicación.

Para una observación visual o de navegación, indicá qué pantalla miraste, qué esperabas encontrar y qué te resultó confuso. Una captura de la demostración puede ayudar. Evitá información de cuentas, tickets, clientes, contraseñas o tokens.

Las propuestas se evalúan como sugerencias. No se publican métricas ni se anuncia una función como disponible antes de comprobarla.
